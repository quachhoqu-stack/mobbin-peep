# mobbin-peep

用于桌面 Chrome / Microsoft Edge 的 Mobbin 浏览辅助扩展，提供截图大图预览、下载、遮罩处理和独立视频播放器。

**版本：1.0.4（混淆发布版）**

下载：[mobbin-peep-v1.0.4.zip](./mobbin-peep-v1.0.4.zip)

## 安装

1. 下载 ZIP，解压到一个固定文件夹。
2. 暂停旧版 Mobbin 本地助手及同类扩展、油猴脚本，避免冲突。
3. 在 Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
4. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择直接包含 `manifest.json` 的文件夹。
5. 确认扩展名为 **mobbin-peep**、版本为 **1.0.4**，刷新已打开的 Mobbin 页面。

请保留解压文件夹，浏览器需要继续从中读取扩展文件。

## 使用

- 鼠标移到截图上，点击“大图”“下载图片”或“复制地址”；有视频资源时会出现“播放视频”。
- 大图支持滚轮缩放、拖动查看、双击还原，按 **Esc** 关闭。
- 点击浏览器工具栏的扩展图标，可分别控制总开关、高清图片、去除遮罩和视频播放器。
- 点击“查看本页视频”，打开当页累计识别的视频列表。
- 需要重试时，点击“重新识别当前页”。安装或重新加载后提示未连接，请先刷新 Mobbin 页面。

## 计数说明

- **本页已加载图片**：已成功加载的截图资源，按资源去重累计。
- **本页已识别视频**：已发现的视频资源，按资源路径去重，与视频列表使用同一份记录。
- 弹窗约每秒更新。滚动回收旧卡片不扣数，换页面路径或查询参数后重新统计，同页 `#` 锚点变化不清零；刷新网页后重新统计。

数字表示已经加载或识别的资源，不是网站标注的全部截图数。识别到视频地址不等于已经验证能够播放。

## 更新及其他说明

更新时替换原解压文件夹中的文件，在扩展管理页点击“重新加载”，然后刷新 Mobbin 页面。

设置保存在本机；图片及原 MP4 通过浏览器下载管理器下载。本版不合并下载 HLS 分片，第三方库及许可证随安装包提供。

本包对自有 JavaScript 做了混淆，不包含源码映射；混淆增加阅读难度，不能彻底隐藏浏览器执行的代码。

验证状态：混淆产物已通过 164 项本地检查及脚本兼容、打包完整性检查；新版本浏览器实站验收尚未完成。
